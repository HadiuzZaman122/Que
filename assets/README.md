# Personal Romantic Photo Assets

This folder is configured for optional personal photos.

You can easily add your own couple photos here or use the **"Personalize with Our Photos"** button directly on the website.

### Recommended Photo Naming:
- `memory-1.jpg` - First date / special memory
- `memory-2.jpg` - Favorite trip / cozy moment
- `memory-3.jpg` - Recent adventure / heartfelt milestone

*Note: The website is designed with luxury procedural vector art vignettes, so it looks stunning and complete even without adding any photos.*
